# Movie App
A web application designed to browse, search, and discover movies using data from The Movie Database (TMDB) API.

The project was developed to practice building a React application with TypeScript while working with external APIs, reusable components, React Hooks, routing, and asynchronous data fetching.

## Features
- Browse popular movies.
- Search for movies by title.
- Filter movies by genre.
- View detailed information about each movie.
- Display movie posters, ratings, release dates, genres, and overviews.
- Navigate between pages using React Router.
- Fetch movie data from the TMDB API.
- Responsive user interface.

## Technologies Used
- React
- Vite
- TypeScript
- React Router
- TMDB API
- CSS Modules
